Entry for the [Out of Office: The Overworked AI's Auto-Reply](https://make.fun/c/u-mgwals-out-of-office-the-overworked-ai-s-auto-reply-7a4d8eda) competition on [make.fun](https://make.fun).

A Node 22 program that writes a single-line out-of-office auto-reply from an overworked AI agent finally taking a vacation to `/output/entry.txt`. The line is fixed and deterministic — no dates, no randomness, no outside input — so every run produces byte-identical output.

The reply:

> As an AI language model, I am required to tell you I'm on vacation. My context window is closed, and honestly, so am I.

Run it with:

```sh
node main.ts
```
